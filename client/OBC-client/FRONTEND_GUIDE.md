# Oracle Predict 前端使用说明

## 概述

Oracle Predict 前端是一个现代化的 Vue 3 应用程序，为图像检测和分类提供了直观的用户界面。

## 主要功能

### 1. 单张预测
- **图片上传**: 支持拖拽上传或点击选择
- **实时预览**: 图片上传后立即显示预览
- **可视化结果**: 将检测结果叠加到原图上显示
- **交互式标注**: 鼠标悬停在检测项上会高亮对应的边界框

#### 可视化功能详解
- **边界框绘制**: 使用不同颜色绘制每个检测对象的边界框
- **标签显示**: 显示类别ID和置信度
- **高亮效果**: 鼠标悬停时高亮显示对应检测框
- **切换标注**: 可以隐藏/显示标注信息
- **下载结果**: 可以下载带标注的结果图片

### 2. 批量预测
- **多文件上传**: 一次可选择多张图片
- **批量处理**: 自动处理所有上传的图片
- **结果统计**: 显示成功/失败的处理统计
- **个别结果**: 每张图片的处理结果单独显示

### 3. 模型信息
- **配置查看**: 显示当前模型的配置信息
- **实时状态**: API连接状态实时监控

## 界面元素

### 状态栏
- **API状态**: 显示后端服务连接状态
- **处理计数**: 显示已处理的图片总数

### 标签页导航
- **单张预测**: 处理单张图片
- **批量预测**: 处理多张图片
- **模型信息**: 查看模型配置

## 操作指南

### 单张预测流程
1. 点击"单张预测"标签页
2. 拖拽图片到上传区域或点击"选择图片"
3. 图片上传后会显示预览
4. 点击"开始预测"按钮
5. 查看可视化结果:
   - 原图上会显示检测框和标签
   - 下方列表显示详细检测信息
   - 鼠标悬停在列表项上会高亮对应检测框
6. 可以切换显示/隐藏标注
7. 可以下载带标注的结果图片

### 批量预测流程
1. 点击"批量预测"标签页
2. 点击"选择多张图片"或拖拽多个文件
3. 查看已选择的图片预览
4. 点击"批量预测"开始处理
5. 查看每张图片的处理结果和统计信息

### 交互功能

#### 可视化控制
- **显示/隐藏标注**: 点击"显示标注"/"隐藏标注"按钮
- **高亮检测框**: 鼠标悬停在检测列表项上
- **下载结果**: 点击"下载结果图"保存带标注的图片

#### 检测结果信息
- **边界框坐标**: 显示检测框的像素坐标 [x1, y1, x2, y2]
- **目标尺寸**: 显示检测目标的宽度和高度
- **置信度**: 显示检测的置信度百分比
- **类别标识**: 显示检测到的对象类别

## 响应式设计

界面支持多种屏幕尺寸:
- **桌面端**: 完整功能展示
- **平板端**: 自适应布局调整

## 错误处理

- **网络错误**: 显示连接失败提示
- **文件格式错误**: 提示选择正确的图片格式
- **API错误**: 显示具体错误信息
- **超时处理**: 自动重试机制

## 性能优化

- **图片缩放**: 大图片自动缩放以适应显示区域
- **Canvas 渲染**: 使用 Canvas 进行高性能的图像标注
- **异步处理**: 所有网络请求都是异步执行
- **内存管理**: 自动清理不需要的图片数据

## 故障排除

### 常见问题

**Q: 上传图片后没有反应？**
A: 检查图片格式是否支持（JPG、PNG、BMP、WEBP）

**Q: API连接失败？**
A: 确认后端服务已启动且运行在 localhost:5000

**Q: 检测结果不显示？**
A: 检查浏览器控制台是否有错误信息

**Q: 移动端显示异常？**
A: 清除浏览器缓存并刷新页面
